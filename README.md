# Prompt Engineering Project 3
## Context-Anchored Answering (RAG Basics)

## Project Overview

This project demonstrates the principles of Retrieval-Augmented Generation (RAG) by restricting an AI model to answer questions using only a provided reference document.

The prompt prevents hallucinations by enforcing strict negative constraints and requiring paragraph citations for every answer.

---

## Objectives

- Implement Context Injection
- Prevent AI Hallucinations
- Use Closed-Book Question Answering
- Apply Negative Constraints
- Generate Paragraph Citations
- Return "Information Not Found" when necessary
